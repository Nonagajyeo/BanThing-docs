## 1. 인증 (Authentication)

### 1-1. 로그인 페이지 (`/login`)

-   **설명**: 사용자가 카카오 소셜 로그인을 통해 서비스에 접근하는 시작점입니다.
-   **화면**:
    ![로그인 페이지](/assets/img/ui/01_login.png)

### 1-2. 서비스 이용 약관 동의 페이지 (`/agreement`)

-   **설명**: 최초 로그인 시, 서비스 이용에 필요한 약관 동의를 받는 페이지입니다.
-   **화면**:

    ![약관 동의 페이지](/assets/img/ui/02_agreement_ui.png)

## 2. 메인 (Main)

### 2-1. 메인 페이지 - 지도 기반 목록 (`/`)

-   **설명**: 카카오맵 API를 연동하여 마트 위치를 마커로 표시합니다. 마커 클릭 시 해당 지점의 모임만 필터링하여 보여주는 핵심 UI입니다.
-   **화면**:
    ![메인 페이지 - 지도 뷰](/assets/img/ui/03_main_map_view.png)

### 2-2. 메인 페이지 - 로딩 상태

-   **설명**: 데이터를 불러오는 동안 사용자 경험(UX)을 개선하기 위해 스켈레톤 UI를 표시합니다.
-   **화면**:
    ![메인 페이지 - 로딩 상태](/assets/img/ui/04_main_skeleton_ui.png)

### 2-3. 메인 페이지 - AI 챗봇

-   **설명**: 우측 하단 플로팅 버튼을 통해 접근하며, 자연어 기반으로 모임을 검색하고 추천받을 수 있는 AI 챗봇 UI입니다.
-   **화면**:
    ![메인 페이지 - AI 챗봇](/assets/img/ui/05_main_chatbot.png)

<br>

## 3. 모임 (Meeting)

### 3-1. 모임 생성 페이지 (`/meeting/create`)

-   **설명**: 사용자가 새로운 소분 모임을 등록하는 페이지입니다. 실시간 유효성 검증 로직이 포함되어 있습니다.
-   **상태 1: 초기 화면**:
    ![모임 생성 - 초기 화면](/assets/img/ui/06_meeting_create_initial.png)
-   **상태 2: 유효성 검사 오류**:
    ![모임 생성 - 오류 화면](/assets/img/ui/07_meeting_create_validation.png)

### 3-2. 모임 상세 페이지 (`/meeting/:id`)

-   **설명**: 모임의 모든 상세 정보, 참여자 목록, 댓글 등을 확인할 수 있는 페이지입니다. 사용자의 역할(주최자/참여자/방문자)에 따라 다른 UI가 제공됩니다.
-   **상태 1: 주최자(Host) 뷰**: 참여 신청을 관리하고 모임을 마감할 수 있는 버튼이 보입니다.
    ![모임 상세 - 주최자 뷰](/assets/img/ui/08_meeting_detail_host.png)
-   **상태 2: 참여자(Participant) 뷰**: 참여 신청 버튼 및 댓글 작성 기능이 활성화됩니다.
    ![모임 상세 - 참여자 뷰](/assets/img/ui/09_meeting_detail_participant.png)
-   **상태 3: 방문자(Visitor) 뷰**: 참여 신청 버튼이 활성화됩니다.
    ![모임 상세 - 방문자 뷰](/assets/img/ui/10_meeting_detail_visitor.png)

### 3-3. 모임 상세 - 참여자 관리

-   **설명**: 주최자가 참여 신청 목록을 보고 승인/거절할 수 있는 UI입니다.
-   **화면**:
    ![참여자 관리](/assets/img/ui/11_meeting_participants_manage.png)

### 3-4. 모임 상세 - 댓글

-   **설명**: 모임 참여자들이 소통할 수 있는 댓글 기능입니다.
-   **화면**:
    ![댓글 기능](/assets/img/ui/12_meeting_comments.png)

### 3-5. 피드백 모달

-   **설명**: 모임이 '완료' 상태로 변경된 후, 참여자들이 서로를 평가할 수 있는 피드백 모달입니다.
-   **화면**:
    ![피드백 모달](/assets/img/ui/13_meeting_feedback_modal.png)

## 4. 마이페이지 (My Page)

### 4-1. 마이페이지 - 내 정보 (`/profile`)

-   **설명**: 사용자의 닉네임, 신뢰도 점수 및 등급을 확인할 수 있는 카드 UI입니다.
-   **화면**:

    ![마이페이지 - 내 정보](/assets/img/ui/14_profile_info.png)

### 4-2. 마이페이지 - 내가 참여한 모임

-   **설명**: 내가 참여 생성한 모임 목록을 '모집중', '진행중', '완료' 탭으로 나누어 보여줍니다.
-   **화면**:
    ![마이페이지 - 주최한 모임](/assets/img/ui/15_profile_hosted_meetings.png)

### 4-3. 마이페이지 - 신청 대기 중인 모임

-   **설명**: 내가 참여 신청을 하고 대기 중인 목록을 상태별로 보여줍니다.
-   **화면**:
    ![마이페이지 - 참여한 모임](/assets/img/ui/16_profile_joined_meetings.png)
