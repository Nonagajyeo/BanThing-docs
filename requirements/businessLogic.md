## 1. 개요

### 1.1 목적
본 문서는 반띵 서비스의 핵심 비즈니스 로직과 규칙을 정의하여 개발팀이 일관된 서비스 로직을 구현할 수 있도록 가이드를 제공한다.

### 1.2 서비스 정의
지도 기반의 대용량 상품 소분 커뮤니티 플랫폼으로, 코스트코, 트레이더스 등 대형마트에서 대용량 상품을 소분하여 구매하는 모임을 연결하는 서비스이다.

### 1.3 적용 범위
- 사용자 관리 및 인증 시스템
- 모임 생명주기 관리
- 지도 기반 검색 및 탐색
- 댓글 및 커뮤니케이션 시스템
- 후기 및 신뢰도 평가 시스템
- AI 챗봇 지원 시스템

## 2. 사용자 관리 및 인증 로직

### 2.1 회원가입 및 로그인 로직

#### 2.1.1 카카오톡 SSO 인증 프로세스
1. 사용자가 카카오톡 로그인 버튼 클릭
2. 카카오 OAuth 2.0 인증 페이지로 리다이렉션
3. 사용자 동의 후 인증 코드 발급
4. 서버에서 인증 코드로 액세스 토큰 요청
5. 카카오 API를 통해 사용자 기본 정보 조회
6. 기존 회원 여부 확인
    - 신규 사용자: 회원 정보 데이터베이스에 생성
    - 기존 사용자: 즉시 로그인 처리
7. JWT 토큰을 생성하고, 보안을 위해 `HttpOnly` 쿠키에 저장 
8. 최초 이용 약관 동의 완료 시, 회원의 약관 동의 필드 갱신

### 2.2 권한 관리 시스템

#### 2.2.1 사용자 권한 레벨
- **비회원(GUEST)**: 모임 목록 조회만 가능
- **참여자(PARTICIPANT)**: 모임 상세 조회 및 댓글 작성 가능
- **호스트(HOST)**: 모임 생성 및 관리 권한 (모임별 부여)
- **관리자(ADMIN)**: 전체 시스템 관리 권한

#### 2.2.2 기능별 접근 제어
- **모임 상세 조회**: 로그인한 회원만 가능
- **모임 신청**: 로그인 한 회원만 가능, 그러나 본인이 생성한 모임에는 불가
- **댓글 작성**: 해당 모임의 호스트 또는 승인된 참여자만 가능
- **후기 작성**: 완료된 모임의 참여자만, 본인 제외 대상에게만 가능

## 3. 모임 관리 로직

### 3.1 모임 생성 및 수정 로직

#### 3.1.1 모임 생성 유효성 검증
1. **필수 정보 검증**
    - 제목: 작성 필수, 100자 이하
    - 장소: 지도 API 연동을 통한 유효한 주소
    - 인원: 최소 2명, 최대 5명

2. **비즈니스 규칙 검증**
    - 동일 사용자의 동일 매장, 동일 시간대 중복 모임 생성 방지

#### 3.1.2 모임 수정 로직
- **수정 권한**: 해당 모임의 호스트만 가능
- **수정 제한**: 모집중, 모집마감 상태에서만 수정 가능
- **변경 알림**: 주요 정보 변경 시 참여자들에게 자동 알림

### 3.2 모임 상태 관리 로직

#### 3.2.1 모임 상태 정의 및 전환
1. **모집중(RECRUITING)**
    - 초기 생성 상태
    - 참여 신청 접수 가능
    - 호스트가 신청자 승인/거절 가능

2. **모집마감(FULL)**
    - 정원 달성 또는 호스트 수동 마감

3. **진행중(ONGOING)**
    - 모임 시작 시간 도달 시 자동 전환

4. **완료(COMPLETED)**
    - 호스트가 수동으로 완료 처리
    - 진행중에서 24시간이 지난 모임들은 자동으로 완료 처리
    - 피드백 기능 활성화

5. **취소(CANCELLED)**
    - 시작 시간이 지났을 때 참여자가 1명 뿐인 모임은 자동으로 취소 처리

### 3.3 참여자 관리 로직

#### 3.3.1 참여 신청 검증 로직
1. **기본 자격 요건**
    - 로그인한 회원만 신청 가능
    - 모집중 상태의 모임만 신청 가능
    - 본인이 생성한 모임 신청 불가

2. **시간 검증**
    - 모임 시작 이후에는 신청 불가

3. **신뢰도 기반 제한**
    - 신뢰도 점수 50점 미만 사용자 참여 금지

#### 3.3.2 호스트 승인 처리 로직
1. **승인 프로세스**
    - 신청자 프로필 및 신뢰도 점수 확인 가능
    - 승인 시 참여자 목록에 추가 및 현재 인원수 증가

2. **거절 프로세스**
    - 거절 이후 재신청 불가능

3. **참여자 거절 로직**
    - 호스트가 승인된 참여자를 거절 가능
    - 신청 상태를 `REJECTED`로 변경하여 이력 보존
    - 제거된 참여자에게 알림 및 사유 전달

## 4. 지도 기반 검색 및 탐색 로직

### 4.1 지도 연동 로직

#### 4.1.1 매장 정보 관리
- **매장 등록**: 관리자가 대형마트 지점 정보를 사전 등록
- **매장 분류**: 코스트코, 이마트 트레이더스 등 브랜드별 분류

#### 4.1.2 모임 위치 기반 검색 로직
1. **지역 선택 검색**
    - 시/도, 시/군/구 지역 단위 선택
    - 선택한 지역 내 모든 매장 및 모임 표시

### 4.2 모임 필터링 및 정렬 로직

#### 4.2.1 필터링 옵션
- **위치 필터**: 특정 매장 선택
- **검색 필터**: 매장 이름, 제목, 소개와 동일한 항목을 필터링

#### 4.2.2 정렬 옵션
- **최신순**: 모임 생성 시간 기준 최신 순

## 5. 댓글 시스템 로직

### 5.1 댓글 접근 권한 관리

#### 5.1.1 읽기 권한
- **전체 공개**: 해당 모임의 호스트 및 승인된 참여자만 조회 가능
- **비참여자 제한**: 신청 대기중인 사용자 및 일반 사용자는 댓글 이용 불가
- **상태별 접근**: 모집중부터 마감까지 모든 상태에서 조회 가능

#### 5.1.2 작성 권한
- **작성 자격**: 호스트 또는 승인된 참여자만 작성 가능
- **실시간 검증**: 댓글 작성 시 현재 참여 상태 재확인
- **상태 제한**: 취소된 모임에서는 댓글 작성 불가

### 5.2 댓글 관리 로직

#### 5.2.1 댓글 생성 
- **길이 제한**: 최대 500자까지 작성 가능

#### 5.2.2 실시간 업데이트
- **동시성 제어**: 여러 사용자의 동시 댓글 작성 시 순서 보장

## 6. 후기 및 신뢰도 평가 시스템

### 6.1 후기 작성 로직

#### 6.1.1 후기 작성 조건
1. **모임 상태 조건**: 완료(COMPLETED) 상태인 모임만 대상
2. **참여자 자격**: 모임에 참여한 사용자만 작성 가능
3. **대상 제한**: 본인을 제외한 다른 참여자들에게만 피드백 가능
4. **중복 방지**: 동일 모임에서 동일 대상에게 중복 피드백 불가

#### 6.1.2 후기 평가 방식
- **평가 항목**: `좋았습니다.`, `싫었습니다.` 버튼 클릭 시 피드백 반영

### 6.2 신뢰도 점수 계산 로직

#### 6.2.1 점수 산정 규칙
1. **기본 활동 점수**
    - 모임 생성: +2점
    - 모임 참여 완료: +1점

2. **후기 기반 점수**
   - 피드백(좋음): +5
   - 피드백(싫음): -5

3. **패널티 점수**
    - 노쇼: -20점

#### 6.2.2 신뢰도 등급 시스템
1. **등급 분류**
    - 좋음(500점 이상): 좋음 배지, 우선 승인 혜택
    - 기본(100-499점): 기본 배지, 제한 없음
    - 경고(0-99점): 경고 배지, 생성 제한, 50점 이하는 참여 제한

## 7. AI 챗봇 지원 시스템

### 7.1 AI 챗봇 기능 정의

#### 7.1.1 지원 범위

1. **소분 관련 정보 제공**
   - 상품별 적정 소분 제품 추천 (견과류, 세제/생활용품, 베이커리, 냉동식품, 육류, 간식, 조미료)
   - 소분 방법 및 보관법 안내
   - 소분 시 필요한 준비물 안내 (개인 용기, 계량도구, 아이스박스, 포장재)
   - 위생 수칙 및 주의사항 제공

2. **모임 검색 및 추천**
   - 자연어 질의를 통한 모임 검색 ("양재점 근처 견과류 소분 찾아줘")
   - 사용자 위치, 상품, 시간대에 맞는 모임 추천
   - 마트별 특징과 장점 설명
   - 거리와 교통편을 고려한 최적의 모임 제안

3. **서비스 이용 가이드**
   - 모임 생성 방법 안내 (제목, 설명, 일시, 장소)
   - 참여 신청 프로세스 설명 (호스트 승인 후 참여 확정)
   - 피드백 시스템 활용법 (모임 완료 후 상호 평가로 신뢰도 관리)
   - 취소 정책 안내 (24시간 전 취소 권장, 노쇼 시 신뢰도 하락)

4. **안전 및 매너 가이드**
   - 만남 장소 및 연락 방법 안내
   - 분쟁 해결 방법 (앱 내 신고 기능 이용)
   - 개인정보 보호 수칙


#### 7.1.2 대화 처리 로직

1. **의도 파악 (Intent Classification)**
   - **MEETING_SEARCH**: 모임 검색 관련 키워드 감지 ("찾", "검색", "추천", "모임", "소분", "참여", "신청", "있나", "어디")
   - **SERVICE_GUIDE**: 서비스 가이드 관련 키워드 감지 ("방법", "어떻게", "가이드", "이용", "사용", "회원가입", "가입", "시작")
   - **GENERAL**: 일반 대화 및 인사

2. **키워드 추출 및 매칭**
   - 지역 키워드: 양재, 양평, 상봉, 고척, 월계, 마곡, 금천, 영등포
   - 마트 키워드: 코스트코, 이마트, 트레이더스, 롯데마트
   - 상품 키워드: 견과류, 아몬드, 호두, 세제, 다우니, 베이커리, 머핀, 베이글, 냉동식품, 만두, 과일, 육류, 삼겹살, 닭가슴살, 간식, 과자, 조미료, 올리브오일, 소스

3. **한계 인식 및 적절한 안내**
   - 회원가입/로그인 관련 질문: "아래 카카오로 시작하기 버튼을 이용해주세요!"
   - 답변 불가능한 질문에 대한 정중한 안내
   - 확실하지 않은 정보는 정확히 모른다고 응답

### 7.2 챗봇 연동 로직

#### 7.2.1 실시간 정보 연동

1. **모임 현황 정보**
   - 현재 모집중인 모임 상태 실시간 조회 (`Meeting.MeetingStatus.RECRUITING`)
   - 참여 가능 여부 확인
   - 모임 일시, 장소, 참여 인원 정보 제공
   - 마트별 활성 모임 현황 통계

2. **참여자 개인화 정보**
   - 사용자의 참여 이력 및 신뢰도 등급 반영 (WARNING/BASIC/GOOD)
   - 닉네임을 활용한 개인화된 응답
   - 노쇼 횟수 및 신뢰도 점수 기반 맞춤 추천
   - 과거 대화 기록 기반 맥락 유지 (로그인 사용자만)

#### 7.2.2 사용자별 서비스 차별화

1. **로그인 사용자 (Authenticated)**
   - 개인화된 시스템 프롬프트 적용
   - 사용자 정보 포함 (닉네임, 신뢰도 점수, 등급, 노쇼 횟수)
   - 대화 기록 저장 및 조회 가능
   - 모임 추천 시 개인 참여 이력 고려
   - 최대 3개 모임 추천 및 추천 이유 제공

2. **게스트 사용자 (Guest)**
   - 기본 서비스 안내 및 회원가입 유도
   - 일반적인 소분 가이드 제공
   - 대화 기록 미저장 (일회성 응답)
   - 키워드 기반 기본 모임 정보 제공

#### 7.2.3 기술적 구현

1. **Google Gemini AI 연동**
   - API 키 기반 클라이언트 설정
   - Temperature: 0.7 (응답 다양성 조절)
   - Max Tokens: 2000 (응답 길이 제한)
   - 모델: gemini-1.5-flash

2. **장애 대응 메커니즘**
   - AI API 장애 시 대체 로직 (Fallback Response) 자동 전환
   - 키워드 기반 모임 매칭으로 서비스 연속성 보장
   - 헬스체크 기능으로 API 상태 모니터링

3. **데이터베이스 연동**
   - 대화 기록 저장 (`ChatbotConversation` 엔티티)
   - 모임 추천 기록 저장 (`ChatbotMeetingSuggestion` 엔티티)
   - 실시간 모임 정보 조회 및 캐싱

#### 7.2.4 보안 및 제약사항

1. **입력 검증 및 제한**
   - 메시지 길이 제한 (최대 1000자)
   - 부적절한 내용 필터링
   - 스팸 방지 메커니즘

2. **개인정보 보호**
   - 링크 및 URL 언급 절대 금지
   - 개인정보 요구 금지
   - 회원가입 안내 시 표준화된 문구만 사용

3. **응답 품질 관리**
   - 친근하고 도움이 되는 톤앤매너 유지
