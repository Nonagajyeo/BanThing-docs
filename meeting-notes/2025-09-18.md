## 논의 내용

### 1) 김경민 작업 현황 및 이슈
- **모임 참여 신청 이슈**: 모임 상세페이지에서 참여 신청 시 참여인원수가 증가되지 않는 문제 발견
- **챗봇 실시간 데이터 연동 문제**: 포스트맨으로 모임 생성 시 모임 상세페이지에서는 조회되나 챗봇에서는 조회되지 않는 이슈
- **UI 개선 계획**: 모임 상세페이지에 참여자 나가기 버튼 및 생성페이지 이동 버튼 추가 예정

### 2) 강관주 백엔드 작업
- **마이페이지 API 개발**: 내가 참여한 모임, 참여 대기중 모임 조회 API 2개 생성 작업
- **추가 작업**: 시간 여유 시 프론트엔드 작업까지 진행 예정

### 3) 송민재 댓글 시스템 개선
- **구조 변경**: 별도 댓글 페이지 대신 모임 상세페이지 내 댓글 컴포넌트로 통합
- **인증 시스템 개선**: useState 대신 Zustand의 authStore 함수를 활용한 로그인 관리 로직 적용
- **추가 작업**: 시간 여유 시 피드백 시스템 프론트엔드 작업 진행
