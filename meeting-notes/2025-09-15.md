## 논의 내용
### 1) 현재 백엔드 작업 진행 상황
- **강관주**: SSO 백엔드 기능 완료됨

### 2) 오늘 각자 작업 분담
- **김경민**:
  - AI 프롬프트 더 디테일하게 작성
- **고동현**: 
  - 지도 API 구현 (프론트엔드 작업 시점으로 연기),
  - 마트 지점별 핀 기능을 카테고리화로 변경 (예외처리 복잡성 해결)
- **송민재**: 상세페이지 댓글 기능 구현
- **강관주**: API 명세서 업데이트 작업, 리액트 컴포넌트 분리작업

### 3) 기술적 이슈 및 해결방안
- **SSO 토큰 관련**: providerId → userId 변환 작업은 프론트엔드와 함께 구현하기로 결정
- **마트 위치 핀**: data.sql이 아닌 schema.sql로 변경하여 카테고리화 구현
