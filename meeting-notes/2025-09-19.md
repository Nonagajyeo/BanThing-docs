## 논의 내용

- **김경민**:
    - 모임 참여자가 신청 후 호스트 승인 시, 상세 페이지 인원 수가 새로고침해야만 반영되는 이슈 확인
    - 참여자가 탈퇴해도 인원 수가 반영되지 않아, 탈퇴 후 재신청 시 인원 수 오류 발생
    - 챗봇에서 실시간 모임 생성 반영이 안 되는 문제 보고
    - 참여자가 신청하면 버튼이 "대기중"(회색)으로 바뀌고, 클릭 불가능 상태로 유지됨 확인

- **송민재**:
    - 댓글 삭제 기능 구현 진행
    - 피드백 기능: 신뢰도 점수에 따라 배지 색깔이 다르게 표시되도록 구현 필요
    - 호스트가 모집 완료 시 피드백 모달이 뜨도록 기능 연계

- **강관주**:
    - 마이페이지 BE, FE 작업 완료
    - 로그인 세션이 5분 이상 유지되지 않는 이슈 발생

- **고동현**:
    - 메인 페이지 모임 생성 시 이미지 업로드가 없을 경우 default 이미지 적용 완료
    - 와이어프레임 문서 최신화 진행

- **공통**:
    - 불필요한 코드, 주석, 파일 정리
