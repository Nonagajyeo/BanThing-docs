# 카카오 맵 API 설정 가이드

반띵 프로젝트의 지도 기반 모임 탐색 기능을 위한 카카오 맵 API 설정 방법을 안내합니다.

## 문서 정보
- **문서명**: 반띵 프로젝트 카카오 맵 API 설정 가이드
- **버전**: v1.1.0
- **작성일**: 2025.09.22
- **작성자**: 김경민
- **최종 수정일**: 2025.09.22

---

## 1. 카카오 개발자 센터 접속

[카카오 개발자 센터](https://developers.kakao.com/)에 접속하여 카카오 계정으로 로그인합니다.

---

## 2. 애플리케이션 설정

### 2-1. 기존 애플리케이션 사용
- 카카오 OAuth 설정에서 생성한 애플리케이션을 그대로 사용합니다
- 새로 만들 필요 없이 **동일한 앱**에서 지도 API도 함께 사용

### 2-2. 내 애플리케이션 선택
- **"내 애플리케이션"** 메뉴에서 반띵 프로젝트 애플리케이션 클릭

---

## 3. 플랫폼 설정 확인

### 3-1. 플랫폼 탭 이동
- 좌측 메뉴에서 **"플랫폼"** 클릭

### 3-2. Web 플랫폼 확인
다음 도메인들이 등록되어 있는지 확인:
- `http://localhost:5173` (프론트엔드 개발 서버)
- `http://localhost:9000` (백엔드 서버)

---

## 4. JavaScript 키 확인

### 4-1. 앱 키 확인
- **"요약 정보"** 탭에서 **JavaScript 키** 확인
- 이 키가 카카오 맵 API에서 사용됩니다

> 🔑 **JavaScript 키**를 프론트엔드 `.env` 파일의 `VITE_KAKAO_APP_KEY`에 설정합니다.

---

## 5. 카카오맵 API 활성화

### 5-1. 제품 설정 > 카카오맵
- 좌측 메뉴에서 **"제품 설정" > "카카오맵"** 클릭

### 5-2. Web API 활성화
- **"Web"** 섹션에서 다음 API들을 **활성화**:
    - ✅ **지도 SDK** (필수)
    - ✅ **장소 검색** (선택)
    - ✅ **좌표-주소 변환** (선택)

---

## 6. 사이트 도메인 등록

### 6-1. 사이트 도메인 설정
카카오맵 설정 페이지에서 **"사이트 도메인"** 등록:
- `http://localhost:5173`
- `http://localhost:9000`

> ⚠️ **중요**: 등록되지 않은 도메인에서는 지도가 표시되지 않습니다.

---

## 7. 프론트엔드 .env 파일 설정

### 7-1. JavaScript 키 설정
프론트엔드 `.env` 파일에 JavaScript 키를 설정:

```bash
# 카카오 맵 API 키 (JavaScript 키 사용)
VITE_KAKAO_APP_KEY=your_kakao_javascript_key_here
```

### 7-2. 주의사항
- ❌ **REST API 키**를 사용하면 안 됩니다
- ✅ **JavaScript 키**만 사용해야 합니다
- 🌐 프론트엔드에서 사용하므로 **VITE_** 접두사 필요

---

## 8. react-kakao-maps-sdk 설정 확인

### 8-1. 패키지 설치 확인
프론트엔드에서 카카오 맵 SDK가 이미 설치되어 있는지 확인:

```bash
cd frontend
npm list react-kakao-maps-sdk
```

### 8-2. 기본 사용법
프로젝트에서 사용하는 기본 구조:

```javascript
import { Map, MapMarker } from 'react-kakao-maps-sdk';

// 환경변수에서 API 키 로드
const { VITE_KAKAO_APP_KEY } = import.meta.env;

// 지도 컴포넌트
<Map
  center={{ lat: 37.566826, lng: 126.9786567 }}
  style={{ width: "100%", height: "400px" }}
  level={3}
>
  <MapMarker position={{ lat: 37.566826, lng: 126.9786567 }} />
</Map>
```

## 9. 테스트 방법

### 9-1. 서버 실행
```bash
# 프론트엔드 실행
cd frontend
npm run dev
```

### 9-2. 지도 표시 확인
1. 브라우저에서 `http://localhost:5173` 접속
2. 메인 페이지의 지도가 정상적으로 표시되는지 확인
3. 마트 위치에 마커가 표시되는지 확인

### 9-3. 개발자 도구 확인
- **F12** 키로 개발자 도구 열기
- **Console** 탭에서 오류 메시지 확인
- 정상적이면 지도 관련 오류가 없어야 함

---

## 10. 주요 기능 설명

### 10-1. 반띵 프로젝트에서 사용하는 기능
- **지도 표시**: 마트 위치 시각화
- **마커 표시**: 코스트코, 이마트 트레이더스 등 마트 지점
- **마커 클릭**: 해당 마트의 소분 모임 목록 표시
- **줌 조절**: 사용자 위치 기반 확대/축소

### 10-2. 마트 데이터 연동
백엔드에서 제공하는 마트 정보:
```json
{
  "martId": 1,
  "martName": "코스트코 양재점",
  "latitude": 37.4699,
  "longitude": 127.0421,
  "martBrand": "COSTCO"
}
```

## 12. 문제 해결

### Q: 지도가 표시되지 않음
**해결방법:**
1. JavaScript 키가 올바른지 확인
2. 사이트 도메인이 등록되어 있는지 확인
3. 브라우저 개발자 도구에서 오류 메시지 확인
4. 카카오맵 API가 활성화되어 있는지 확인

### Q: "Uncaught ReferenceError: kakao is not defined"
**해결방법:**
1. `react-kakao-maps-sdk` 패키지 설치 확인
2. `.env` 파일의 `VITE_KAKAO_APP_KEY` 설정 확인
3. 컴포넌트에서 올바른 import 사용

### Q: 마커가 표시되지 않음
**해결방법:**
1. 위도/경도 좌표값 확인
2. 마커 컴포넌트 구문 확인
3. 지도 레벨(줌) 조정

### Q: "Invalid site domain" 오류
**해결방법:**
1. 카카오 개발자센터에서 사이트 도메인 재등록
2. 현재 접속 중인 도메인과 등록된 도메인 일치 확인
3. `https`/`http` 프로토콜 일치 확인

### 13-1. 도메인 설정

- 도메인 제한으로 보안 강화
- 민감한 기능은 서버 사이드에서 처리

### 13-3. 성능 최적화
- 지도 로딩 최적화
- 마커 클러스터링 (많은 마커 표시 시)
- 필요한 지역만 데이터 로드
