# 카카오 OAuth 설정 가이드

반띵 프로젝트에서 카카오 소셜 로그인을 위한 OAuth 설정 방법을 안내합니다.

## 문서 정보
- **문서명**: 반띵 프로젝트 카카오 OAuth 설정 가이드
- **버전**: v1.1.0
- **작성일**: 2025.09.22
- **작성자**: 김경민
- **최종 수정일**: 2025.09.22

---

## 1. 카카오 개발자 센터 접속

[카카오 개발자 센터](https://developers.kakao.com/)에 접속하여 카카오 계정으로 로그인합니다.

---

## 2. 애플리케이션 생성

### 2-1. 내 애플리케이션 이동
- 상단 메뉴에서 **"내 애플리케이션"** 클릭

### 2-2. 애플리케이션 추가하기
- **"애플리케이션 추가하기"** 버튼 클릭
- **앱 이름**: `반띵 (또는 원하는 이름)`
- **사업자명**: `개인 개발자 (또는 팀명)`
- **카테고리**: `라이프스타일` 또는 `커뮤니티`

---

## 3. 앱 키 확인

생성된 애플리케이션의 **"요약 정보"** 탭에서 다음 키들을 확인합니다:

- **REST API 키**: OAuth에서 사용 ✅
- **JavaScript 키**: 카카오 맵에서 사용 ✅
- **Admin 키**: 사용 안 함

> 🔑 **REST API 키**를 `.env` 파일의 `KAKAO_CLIENT_ID`에 설정합니다.

---

## 4. 플랫폼 설정

### 4-1. 플랫폼 탭 이동
- 좌측 메뉴에서 **"플랫폼"** 클릭

### 4-2. Web 플랫폼 등록
- **"Web 플랫폼 등록"** 클릭
- **사이트 도메인**: `http://localhost:5173` (프론트엔드 개발 서버)
- **추가**: `http://localhost:9000` (백엔드 서버 - 필요시)

---

## 5. 카카오 로그인 설정

### 5-1. 제품 설정 > 카카오 로그인
- 좌측 메뉴에서 **"제품 설정" > "카카오 로그인"** 클릭

### 5-2. 카카오 로그인 활성화
- **"카카오 로그인 활성화"** ON으로 설정

### 5-3. Redirect URI 설정
- **"Redirect URI"** 섹션에서 **"Redirect URI 등록"** 클릭
- **Redirect URI**: `http://localhost:9000/login/oauth2/code/kakao`

> ⚠️ **중요**: Redirect URI는 반드시 백엔드 서버 주소여야 합니다.

---

## 6. 동의항목 설정

### 6-1. 제품 설정 > 카카오 로그인 > 동의항목
- **"동의항목"** 탭 클릭

### 6-2. 필수 동의항목 설정
다음 항목들을 설정합니다:

| 항목 | 설정 | 설명 |
|------|------|------|
| **닉네임** | 필수 동의 | 사용자 식별용 |
| **프로필 사진** | 선택 동의 | 프로필 이미지 |
| **카카오계정(이메일)** | 선택 동의 | 추가 식별 정보 |

### 6-3. 개인정보 보호정책
- **개인정보 보호정책**: 추후 배포 시 작성 (개발 단계에서는 생략 가능)

---

## 7. 클라이언트 시크릿 발급

### 7-1. 보안 탭 이동
- **"제품 설정" > "카카오 로그인" > "보안"** 탭 클릭

### 7-2. Client Secret 발급
- **"Client Secret"** 섹션에서 **"코드 생성"** 클릭
- **"활성화 상태"**를 **ON**으로 설정

> 🔑 **Client Secret**을 `.env` 파일의 `KAKAO_CLIENT_SECRET`에 설정합니다.

---

## 8. .env 파일 설정

발급받은 키들을 백엔드 `.env` 파일에 설정합니다:

```bash
# OAuth2 설정
KAKAO_CLIENT_ID=your_rest_api_key_here
KAKAO_CLIENT_SECRET=your_client_secret_here
```

---

## 9. 테스트 방법

### 9-1. 서버 실행
```bash
# 백엔드 실행
./gradlew bootRun

# 프론트엔드 실행 (새 터미널)
cd frontend
npm run dev
```

### 9-2. 로그인 테스트
1. 브라우저에서 `http://localhost:5173` 접속
2. 로그인 버튼 클릭
3. 카카오 로그인 팝업 확인
4. 로그인 후 사용자 정보 표시 확인

---

## 10. 주의사항

### 10-1. 개발/운영 환경 분리
- **개발**: `localhost` 도메인 사용
- **운영**: 실제 도메인으로 설정 변경 필요

### 10-2. 보안
- **Client Secret**은 절대 프론트엔드에 노출하면 안 됩니다
- `.env` 파일은 Git에 커밋하지 않습니다

### 10-3. 쿼터 제한
- 카카오 로그인은 일일 쿼터 제한이 있습니다
- 개발 단계에서는 충분하지만, 운영 시 쿼터 확장 신청이 필요할 수 있습니다

---

## 11. 문제 해결

### Q: 로그인 시 "invalid_client" 오류
A: `KAKAO_CLIENT_ID`와 `KAKAO_CLIENT_SECRET` 확인

### Q: "redirect_uri_mismatch" 오류
A: 카카오 개발자센터의 Redirect URI 설정 확인

### Q: 동의항목 관련 오류
A: 필요한 동의항목이 올바르게 설정되었는지 확인

---

> 설정이 완료되면 반띵 서비스에서 카카오 소셜 로그인을 사용할 수 있습니다!
