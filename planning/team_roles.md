## 팀원별 상세 기여

### 김경민 (팀장)

* **Backend**: Google Gemini API 연동, AI 챗봇 시스템 설계 및 구현, REST API 엔드포인트(/message, /guest, /history, /health, /intro) 설계, 키워드 추출 및 의도 분류, 모임 추천 알고리즘, AI API 장애 대응 폴백 로직
* **Frontend**: React 기반 챗봇 UI/UX, 실시간 대화 인터페이스(타이핑 인디케이터, 스크롤 자동 고정, 에러 핸들링), 로그인/비로그인 사용자별 구분 UI
* **Docs & 관리**: 회의록 작성 및 관리, README, 환경설정 가이드, 챗봇 API 명세서, 컬러 가이드, Git 워크플로우, 배포 가이드

### 고동현

* **Backend**: 모임 CRUD API, 마트 조회 및 위치 기반 API, 모임 참여/삭제/완료 API, 참여자 관리 시스템(승인/거절/마감), 모임 상태 자동화 스케줄러
* **Frontend**: 메인 페이지, 카카오 맵 API 연동, 지도-목록 필터링, 모임 생성 페이지(실시간 유효성 검증), 참여자 관리 UI
* **Docs & 산출물**: 프로젝트 배경 및 경쟁사 분석 문서, 시장 조사, 와이어프레임, 스케줄러/카카오맵 SDK 기술 명세서, 발표 자료

### 강관주

* **Backend**: Spring Security와 JWT 인증/인가 아키텍처, HttpOnly 쿠키 기반 토큰 관리, 카카오 OAuth2.0 기반 SSO 연동, Access Token 재발급, 로그아웃 API, 참가 모임/승인 대기 모임 조회 API
* **Frontend**: 카카오 로그인 연동 및 콜백 처리, 로그인/약관동의 페이지, 마이페이지(스켈레톤 UI + 페이지네이션)
* **Docs & 산출물**: 서비스 기능 요구사항 정의, 개념 데이터 모델링 및 ERD, 개인정보 처리방침/이용약관 등 법적 리스크 문서, 외부 API 연동 명세서

### 송민재

* **Backend**: 댓글 작성/수정/삭제/조회, 피드백 작성/조회 API
* **Frontend**: 댓글 모달창(수정/삭제), 피드백 모달창, 댓글/피드백 작성 UI(조건부 렌더링), 신뢰도 점수 기반 뱃지 색상 변경, 마이페이지 뱃지 추가
* **Docs & 산출물**: 타겟 시장 분석, 페르소나 분석, 기술 명세서, 일반 API 명세서, ERD 및 테이블 스키마 수정

### 박현수

* **Docs 전담**: 사용자 플로우 작성, 비즈니스 로직 문서화

## 팀 공통 성과

### 아키텍처 & 설계

* **데이터베이스 설계**: 7개 테이블 기반 통합 스키마 설계
* **REST API 설계**: RESTful 원칙 준수한 API 명세서 작성
* **시스템 아키텍처**: Spring Boot + React 분리형 아키텍처
* **스케줄러 시스템**: 모임 상태 자동 관리 구현

### 기술적 성과

* **카카오 API 통합**: 지도 SDK, OAuth SSO 완전 연동
* **AI 챗봇 구현**: Google Gemini API 기반 자연어 모임 검색
* **보안 시스템**: JWT 기반 인증 + Spring Security
* **상태 관리**: Zustand 기반 프론트엔드 전역 상태 관리
* **반응형 웹**: 모바일 퍼스트 디자인 적용

### 협업 & 프로세스

* **Git 워크플로우**: feature 브랜치 전략 및 PR 리뷰 확립
* **커밋 컨벤션**: \[BE]/\[FE] 태그 활용
* **문서화**: 총 15회의 회의록 및 기술 문서 관리
* **이슈 추적**: GitHub Issues & PR 템플릿 활용

### 비즈니스 성과

* **MVP 완성**: 지도 탐색, 모임 관리, 챗봇 구현 완료
* **사용자 경험**: 직관적 지도 기반 UI, 간편한 소셜 로그인
* **확장 가능성**: Phase 2, 3 로드맵 수립
* **시장 차별화**: SNS 기반 소분 모임의 한계를 해결하는 플랫폼

### 개발 지표

* **개발 기간**: 총 19일 (기획 7일 + 개발 12일)
* **API 엔드포인트**: 20+ REST API 구현
* **테이블 설계**: 7개 테이블, 외래키 제약조건 포함 정규화
* **더미 데이터**: 8개 모임, 8명 사용자, 10개 마트 테스트 데이터

### 지속적 개선

* **환경 설정 자동화**: .env 기반 환경 변수 관리
* **코드 품질**: Lombok, Spring DevTools 활용
* **테스트 환경**: H2 인메모리 DB 도입
* **문서 관리**: 별도 docs 레포지토리 체계적 관리
